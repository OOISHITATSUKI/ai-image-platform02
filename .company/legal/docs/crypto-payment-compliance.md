# 仮想通貨決済と金融庁届出に関する整理

## 発端

2026年3月、金融庁が「SANAE TOKEN（サナエトークン）」の関連業者への調査を検討しているとのニュースが報じられた。これを受けて、当サービスの仮想通貨決済が金融庁への届出を必要とするか整理する。

## SANAE TOKEN問題の概要

- 独自の仮想通貨トークン「SANAE TOKEN」を発行・販売していた
- 暗号資産交換業者としての登録（資金決済法に基づく）を行っていなかった
- 金融庁が「無登録で暗号資産の発行・交換業を行っている可能性」として調査を検討

## 当サービスとの比較

| 項目 | SANAE TOKEN | 当サービス |
|------|------------|-----------|
| 何をしているか | 独自トークンの**発行・販売** | 既存の仮想通貨で**決済を受け取る** |
| トークン発行 | あり（独自トークン） | **なし** |
| 暗号資産の売買・交換 | あり | **なし** |
| 決済方法 | 独自トークンの購入 | NowPayments経由でBTC/ETH/USDT等を受領 |
| サービス内通貨 | トークン自体が流通 | クレジット（換金・譲渡不可） |
| 法的リスク | 暗号資産交換業の無登録営業 | **該当なし** |

## 結論：金融庁への届出は不要

当サービスは以下のいずれにも該当しない。

### 1. 暗号資産交換業（資金決済法第2条第15項）

- 仮想通貨の売買・交換を業として行っていない
- 独自トークンを発行していない
- NowPaymentsが決済代行として仮想通貨を受領し、当社はサービス内クレジットを付与するのみ

### 2. 前払式支払手段の発行（資金決済法第3条）

- サービス内クレジットは以下の設計により「前払式支払手段」の定義から外れる：
  - 法定通貨への換金不可
  - 仮想通貨への再変換不可
  - 他のアカウントへの移転不可
  - 第三者への譲渡不可
  - 返金不可
- 自社サービス内でのみ消費される数値であり、「支払手段」として流通しない

### 3. 資金移動業（資金決済法第2条第3項）

- ユーザー間の送金機能は提供していない
- 当社からユーザーへの払い戻し・送金も行わない

## 安全な設計を維持するために守るべきルール

以下の設計原則を**絶対に変更しないこと**：

### ✅ 守ること
- クレジットは自社サービス内でのみ使用可能
- クレジットの換金・返金は一切不可
- クレジットの他アカウントへの移転不可
- 独自トークンは発行しない
- 決済はNowPayments経由のみ（ウォレットアドレスの直接管理なし）

### ❌ やってはいけないこと（やると届出が必要になる）
- 独自の仮想通貨トークンを発行する
- ユーザー間でクレジットを送り合える機能を作る
- クレジットを仮想通貨や法定通貨に換金できるようにする
- ユーザーの仮想通貨を預かる（カストディ）
- 仮想通貨の売買・交換機能を提供する

## 法人所在地との関係

- 当サービスはエストニア法人として運営予定
- 準拠法はエストニア共和国の法律（利用規約第14条）
- 日本向けに提供する意図はない旨を明記済み
- この構成により、日本の金融庁への届出義務は発生しない

**注意**: 将来的に日本法人を設立する場合や、日本居住者を明示的にターゲットにする場合は、改めて法的確認が必要。

## 利用規約での対応状況

| 条項 | 内容 | 対応状況 |
|------|------|---------|
| 第10条1項 | クレジットはサービス内でのみ使用可能 | ✅ |
| 第10条1項3号 | 換金・再変換・移転の禁止 | ✅ |
| 第10条2項 | 返金不可の明記 | ✅ |
| 第10条3項 | 決済はNowPayments経由 | ✅ |
| 第14条 | 準拠法はエストニア法 | ✅ |
| 第14条3項 | 禁止地域への非提供意図 | ✅ |

## 最終判断

当サービスの仮想通貨決済は「既存の仮想通貨で代金を支払う」仕組みであり、「独自トークンを発行・販売する」仕組みではない。したがって、金融庁への届出は不要。現在の設計（クレジット換金不可・返金不可・移転不可）を維持する限り、SANAE TOKENのような問題は発生しない。
