# エディターUI改修

## 概要
初回ユーザーがエディターで離脱している問題への対応。
20クレジット保持しているが生成ゼロのユーザーが複数確認された。

## 問題
- 「何をすればいいか分からない」が最大の壁
- 3ペインレイアウトが初回ユーザーには情報過多

## 対応方針
- 3ペイン → 2ペイン レイアウト変更
- ワンクリック生成ボタン（初回ユーザー向け）
- プロンプト欄のプレースホルダーローテーション
- 設定・Character Tags をデフォルト折りたたみ
